The exact my-app todo API is checked with its actual /sur and mark reader fixtures. tools/test-arms checks the API fixture against the application source through tests/my-app-copies.txt. Positive and negative reports cover request callback polymorphism, the named one-diff fold, typed path arguments, poke, exported molds and a typed subscription expression. The interface guards check source and request evidence and reject missing or duplicate inputs, unsupported sibling declarations and private imports. Reports are partial inference, not a complete module check or runtime/watchability proof.
